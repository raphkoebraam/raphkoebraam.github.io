Mirage

Open-source command-line tool for Apple simulators, built in Swift on top of xcrun simctl. Mirage lets you address simulators by name instead of UDID, picks sensible defaults (booted device, newest runtime), and adds what simctl lacks: a safe cleanup with a dry run, disk-usage reporting, a doctor command, JSON output for scripting, and shell completions. Distributed via Homebrew and mise as a single universal binary, with CI-friendly behavior (honest exit codes, explicit confirmation for destructive commands, isolated device sets).
